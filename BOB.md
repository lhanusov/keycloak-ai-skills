# Keycloak AI Skills

When asked to create or scaffold a reusable skill, read [add-skill](skills/add-skill/SKILL.md) and follow its instructions. Resolve that path and its supporting resources from this installed extension directory, not the user's project. Load the skill only when it applies to the request.

When asked to triage a specific Keycloak issue for duplicates, security impact, or CVE relevance, read [triage-cve](skills/triage-cve/SKILL.md) and follow its instructions. Resolve its resources from this installed extension directory. The skill produces a report and proposed comment.
