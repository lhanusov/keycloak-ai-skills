# Keycloak AI Skills 0.5.2

- `add-skill` now advertises revisions to existing workflows, decision rules, and reference loading in its description, README entry, and Bob route. Use `update-skill` to check existing guidance against changed upstream sources.
- The shared GitHub CLI guidance now checks that a job ID appears in the requested workflow attempt before retrieving its log. The CI diagnosis reference links to that procedure.

## Validation

The package and shared-reference checks passed, along with all 49 unit tests. Offline checks covered skill selection for workflow revisions and upstream reference refreshes, plus six GitHub tool-use scenarios. Skill activation in installed clients remains untested.

Using GitHub CLI 2.105.0, we verified that the documented commands listed jobs for the second attempt of a public Keycloak documentation workflow and retrieved the build log for the selected job.

## Upgrade

Update the plugin or extension through your client's installation workflow and start a new session. For standalone installations, copy the complete skill directory.
