# Keycloak AI Skills 0.5.1

All ten skills now use GitHub CLI (`gh`) by default when a task needs GitHub data or authorized actions. Explicit user tool preferences still apply. Workflows continue with authorized alternatives when the CLI is unavailable or cannot retrieve the required evidence; non-GitHub trackers use their appropriate clients.

## GitHub access guidance

Shared CLI guidance is bundled inside each skill for standalone use. It covers explicit host/repository/revision context, issue and duplicate searches, PR diffs and review feedback, independent pagination of threads and comments, CI run/attempt/job provenance, source retrieval, and authorized publication. Existing confidentiality and authorization boundaries remain in effect. Local-only skill authoring needs no GitHub access.

## Validation and limits

Generated-guidance and package checks and all 49 automated tests passed during preparation. Six paired offline scenarios checked tool selection, pagination, CI provenance, unavailable-CLI fallbacks, confidential non-GitHub records and authoring/reference retrieval. The baseline preferred connectors in four cases where both tools were available; the candidate selected `gh` in those cases while preserving the evaluated boundaries.

CLI examples were checked against installed `gh` 2.105.0 help. These checks do not establish live GitHub API behavior, repeated-run reliability or installed-client activation. No live GitHub operations or Keycloak changes were performed during authoring.

## Upgrade

Update the plugin or extension through your client's existing installation workflow and start a new session. Standalone installations must copy the complete skill directory, including its bundled resources.
